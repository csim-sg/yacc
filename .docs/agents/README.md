## 🎯 HOW TO USE

### For Quick Reference
Read `packages/backend/AGENTS.md` for essentials and quick commands.

### For Deep Dives
When you need detailed information on a topic:
1. Find the topic in `.docs/agents/`
2. Read the relevant guide
3. Follow examples and best practices

- Use as reference documentation
- Search for specific patterns
- Study code examples

### For AI Agents (GLM 4.7)

- Check checklists before completing tasks
